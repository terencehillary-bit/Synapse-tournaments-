SYNAPSE TOURNAMENTS WEBSITE
===========================

Files:
- index.html: website content
- styles.css: responsive black/white/lime visual theme
- script.js: mobile navigation and current year
- assets/synapse-logo.png: supplied Synapse logo

PREVIEW
Open index.html in a browser. An internet connection is needed for the Google Fonts and remote sports photography.

PUBLISHING
This is a static website, ready for a static host such as Netlify or GitHub Pages.
Upload the contents of this folder (not the ZIP itself if the host asks for a folder).
Once the site is published and you have its final public HTTPS URL, generate the website QR code from that exact URL. A QR code made before publishing would point to a guessed or non-working address.
